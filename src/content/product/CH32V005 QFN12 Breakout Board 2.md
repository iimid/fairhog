# CH32V005 QFN12 Breakout Board

A DIP14 300-mil breakout board for the WCH CH32V005 microcontroller.  
Product ID: DCY05

## Features

- CH32V005 RISC-V MCU in QFN12 Package
- Brings out all the signals from the MCU
- Single wire SDIO programming & debug
- Narrow width DIP14 compatible PCB

## Specifications

| Item              | Specification                                           |
|-------------------|---------------------------------------------------------|
| MCU               | CH32V005D6U6                                            |
| Interface         | 11 GPIOs, 1 Indipendent LED                             |
| Board Size        | 18.8 x 10.12 mm, t = 1.2 mm                             |
| MCU Core Spec.    | ROM 32 KB, RAM 6 KB, 48 MHz                             |
| Operating Voltage | 2.0 - 5.5 V (2.4 - 5.5 V with ADC)                      |
| Debug Port        | Dedicated 3-pin (SWIO, GND, VCC)                        |
| Luminous Color    | LED1: <div class="color-box aquamarine">Turquoise</div> |
