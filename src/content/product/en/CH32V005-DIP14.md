# CH32V005 DIP14 Breakout Board

A DIP14 300-mil breakout board for the CH32V005 RISC-V microcontroller.  
Product ID: DCY05

## Features

- WCH CH32V005 MCU in QFN12 Package
- All MCU pins are broken out to the headers
- SDI, Single-wire programming and debugging interface
- Space-saving DIP14 compatible form factor

## Specifications

| Item              | Specification                                           |
|-------------------|---------------------------------------------------------|
| MCU               | CH32V005D6U6                                            |
| Interface         | 11 GPIOs, 1 Independent LED                             |
| Board Size        | 18.8 x 10.12 mm, t = 1.2 mm                             |
| MCU Specification | ROM 32 KB, RAM 6 KB, CLK 48 MHz                             |
| Operating Voltage | 2.0 - 5.5 V (2.4 - 5.5 V with ADC)                      |
| Debug Port        | Dedicated 3-pin (SWIO, GND, VCC)                        |
| Luminous Color    | LED1 <div class="color-box aquamarine">Turquoise</div> |
