# CH32V005 DIP14 Breakout Board

A DIP14 300-mil breakout board for the CH32V005 RISC-V microcontroller.  
Product ID: DCY05 | RoHS Compliant

## Features

- Breakout board for the CH32V005 in a QFN12 package
- All MCU pins broken out to headers
- WCH's Serial Debug Interface for single-wire programming and debugging
- Space-saving DIP14-compatible footprint
- ENIG surface finish

## Specifications

| Item              | Specification                                           |
|-------------------|---------------------------------------------------------|
| MCU               | WCH CH32V005D6U6                                        |
| Board I/O         | 10 GPIOs, 1 SDIO or GPIO, 1 Independent LED+            |
| Board Size        | 18.8 x 10.12 mm, t = 1.2 mm                             |
| MCU Specification | ROM 32+3 KB, RAM 6 KB, CLK 48 MHz                       |
| Operating Voltage | VCC: 2.0 - 5.5 V (2.4 - 5.5 V with ADC) </br> LED+: 3.2 - 7.0 V |
| Debug Port        | Dedicated 3-pin (SWIO, GND, VCC)                        |
| Misc. Spec.       | LED1 <div class="color-box aquamarine">Turquoise</div>  |
